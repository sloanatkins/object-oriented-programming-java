# Object-Oriented Programming with Java

This repository contains Java programming coursework from a foundational computer science course focused on object-oriented programming, algorithms, and problem solving.

## Course Context
**Computer Programming I (CSC 120)**  
This course introduces fundamental programming constructs, algorithmic thinking, and object-oriented programming concepts. Topics include classes and objects, recursion, basic data structures, and structured problem solving.

## Topics & Skills
- Java syntax and object-oriented programming
- Classes, objects, and encapsulation
- Control flow and recursion
- Algorithm design and problem solving
- Debugging and program structure
- Translating problem statements into code

## Repository Structure
- `/Week X` – Weekly programming exercises and labs
- `/Sloan_Atkins_CSC120_Midterm_Project` – Larger applied programming project
- `/Sloan_Atkins_CSC120_Project2` – Additional project-based assignment

## Notes
This repository reflects early-stage object-oriented programming coursework and emphasizes correctness, clarity, and core software design principles.
